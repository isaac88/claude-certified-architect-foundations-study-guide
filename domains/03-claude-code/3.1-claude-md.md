# 3.1 CLAUDE.md hierarchy

Claude Code loads memory from three layers. The exam’s favourite bug is putting **team law** in the **personal** layer.

## Three levels

| Level | Typical path | Who gets it? | Git? |
|---|---|---|---|
| **User** | `~/.claude/CLAUDE.md` | Only you, on that machine | No |
| **Project** | `.claude/CLAUDE.md` or repo-root `CLAUDE.md` | Everyone who clones/pulls | Yes |
| **Directory** | `CLAUDE.md` inside a subdirectory | When work is in that tree | Yes |

User-level is for personal taste (how *you* like commit messages). It is **not** the team API naming guide.

A new teammate clones the repo and Claude ignores your conventions → look at **user-level** first. Developer A’s `~/.claude/CLAUDE.md` is invisible to Developer B.

## Modular organisation

One 2,000-line CLAUDE.md wastes tokens and hides the rule you need.

- **`@import`** from CLAUDE.md to pull package-specific standards (`@docs/standards/payments.md`) so each package loads what it needs.
- **`.claude/rules/`** for topic files (`testing.md`, `api-conventions.md`, `deployment.md`) instead of one blob. Path-scoped rules (3.3) live here too.

## `/memory`

Debugging tool. Shows **which memory files are actually loaded** this session. Use it when:

- Two developers see different behaviour on the same repo
- A rule you wrote “isn’t applying”
- You are unsure whether user-level is leaking in

Do not guess. Run `/memory`.

## Practice scenario

Developer A’s Claude follows the team API naming conventions. Developer B joined last week; naming is inconsistent. Same repo, same branch.

| Option | Verdict |
|---|---|
| **A. Instructions live in A’s `~/.claude/CLAUDE.md`** | **Correct.** B never received them. Move to project `.claude/CLAUDE.md`. |
| B. B needs a bigger model | Distractor. Not a model-size problem. |
| C. B forgot to run `/review` | Commands are not how universal standards load. |
| D. Add the conventions to a personal skill on B’s laptop | Still not shared; next hire fails too. |

## Check questions

1. Where do testing standards the whole team must follow live?
2. Claude “ignores” a rule you added yesterday. First debugging command?
