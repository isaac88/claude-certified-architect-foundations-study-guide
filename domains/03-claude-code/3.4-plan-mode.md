# 3.4 Plan mode vs direct execution

## Decision framework

**Plan mode** when:

- Large-scale change (monolith → services, 45-file library migration)
- **Several valid approaches** — you must choose before committing
- Architectural decisions (boundaries, ownership, data flow)
- You need to **explore** the codebase before touching it

**Direct execution** when:

- Scope is clear and small
- Single-function bug with a stack trace (null pointer in one method)
- The approach is already known (add a date-validation `if`)
- A well-understood one-liner / local fix

**Always plan** wastes money on `typo in README`.  
**Never plan** is how you rewrite half the repo then discover the wrong service cut.  
If the request is *already* obviously architectural, start in plan mode — do not “try direct and switch if it hurts”.

## Explore subagent

Verbose discovery (wide Grep, reading trees) **exhausts the parent context**. Explore (read-only, isolated) returns a **summary** to the main session. Use it in multi-phase work so the parent keeps decision-making room (ties to 1.6 / 5.4).

## Hybrid (tested)

1. Plan mode (and Explore) — map, compare options, write the plan.  
2. Direct execution — implement the agreed plan.

Do not stay in plan mode to type the actual patches once the design is settled.

## Practice scenario — classify these three

| Task | Mode | Why |
|---|---|---|
| 1. Restructure a monolith into microservices | **Plan** | Architecture, many files, multiple valid cuts |
| 2. Fix a null pointer in a single function | **Direct** | Known defect, local scope, stack trace |
| 3. Migrate logging library across 30 files | **Plan** (then direct to implement) | Multi-file, mechanical but high blast radius; need a consistent approach first. Not “just start editing file 1” without a plan. |

Logging migration is the borderline the exam likes: 30 files is not a one-function fix. Plan the replacement pattern, then execute. Pure plan-forever is wrong once the pattern is chosen.

## Check questions

1. 45-file library migration: plan, direct, or hybrid?
2. Why isolate Explore output from the main conversation?

## Connects to 3.5

Once you are executing, *how* you steer Claude matters: examples and tests beat “make it better”.
