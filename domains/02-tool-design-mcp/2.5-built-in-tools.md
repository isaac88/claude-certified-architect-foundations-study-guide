# 2.5 Built-in tools

Never use Bash when a dedicated tool exists. `Bash("cat config.json")` is a standard wrong answer. Use `Read`.

## Grep vs Glob

The exam will give you a job that matches **one** of these. Using the other wastes a turn or returns nothing useful.

| | **Grep** | **Glob** |
|---|---|---|
| Matches | File **contents** | File **paths** / names |
| Use for | Callers of a function, error strings, import lines | `**/*.test.tsx`, finding `webpack.config.js` |
| Will not do | Find files by extension alone | Find a function name inside files |

## Read / Write / Edit

| Tool | Job |
|---|---|
| `Read` | Load a file (or a range) |
| `Write` | Create a file, or **replace the entire file** |
| `Edit` | Targeted patch via unique text match — fast, precise |

`Write` on an existing file **drops anything you omit**. Do not “Write the whole file from memory” to change three lines.

**When Edit fails** (the old string is not unique, or the file drifted): fallback is `Read` the file, then `Write` the complete corrected contents (or a more unique `Edit` hunk). Not `sed` via Bash as the designed path.

## Incremental codebase understanding

Do **not** Read the repository. Context budget dies.

1. **Grep** for entry points (function definition, symbol, error message).
2. **Read** those files; follow imports.
3. Grep again for exported names to find wrappers and callers.
4. **Glob** when you need a set of paths (`**/*.{spec,test}.ts`).

Trace wrappers: identify the **exported names**, then Grep each name. Do not glob `**/*` and Read them all.

## Practice scenario

Find every file that calls deprecated `charge_legacy()`, then find the test files for those callers.

1. **Grep** `charge_legacy` — content search yields caller files (and the definition).
2. From caller paths (`payments/processor.py`, `api/billing.py`), **Glob** likely tests: `**/test*processor*`, `**/*billing*.test.*`, or `**/*.test.py` then filter — Glob is path-shaped; you may Grep those test files for `processor` / `charge_legacy` if names do not match.

Wrong sequence: Glob `**/*.py` then Read everything; Grep `*.test.py` as if Grep were Glob; Bash `find | xargs grep`.
