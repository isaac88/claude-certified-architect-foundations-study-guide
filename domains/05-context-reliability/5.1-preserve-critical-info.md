# 5.1 Context preservation

## Progressive summarisation trap

Summarisers eat **numbers**.  

“Customer wants a refund of **$247.83** for order **#8891** placed on **3 March**” becomes “customer wants a refund for a recent order”.

That is how you refund the wrong amount on the wrong order.

**Fix:** extract transactional facts into a persistent **case facts** block. Include it in **every** subsequent prompt. **Never** summarise it. Narrative summary is allowed only for the fluffy middle of the chat.

Typical case facts: customer ID, verified name, order numbers, amounts, dates, policy decisions already taken.

## Lost in the middle

Models attend to the **start** and **end** of long inputs. Findings buried mid-context vanish.

**Fix:** put a **key-findings summary at the beginning**. Use explicit section headers throughout so nothing is an undifferentiated blob.

## Trim tool results before append

Order lookup returns 40 fields; you need five. Trim **before** you append to history. Accumulated verbose payloads exhaust the token budget and drown the case facts.

## Full history on every request

The API is **stateless**. The next call must carry the conversation you still need. Dropping early turns (without a deliberate case-facts + summary design) breaks coherence. “I already told you the order id” is on you, not the model.

## Upstream agents: structured, not essays

Spokes that return reasoning chains and raw HTML waste the downstream window. Require **key facts, citations, relevance scores** (ties to 1.3 and 5.6). Critical when the next agent is small-context.

## Practice

Forty-turn support chat. Order IDs and the refund amount disappear after `/compact`-style summarisation.

**Root cause:** those values lived only in summarised prose.  
**Fix:** case-facts block, re-injected every turn; trim `lookup_order` to the five fields you use.

## Check questions

1. What belongs in case facts vs the rolling summary?
2. A research coordinator concatenates three 8k-token spoke essays. What should change **upstream**?
