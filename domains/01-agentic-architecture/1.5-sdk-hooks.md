# 1.5 Agent SDK hooks

Hooks are code that runs on the agent lifecycle. They are **deterministic**. Prompts are **probabilistic**. If the business would lose money or face legal risk from a single miss, use a hook.

## PostToolUse

Runs **after** the tool executes, **before** the model sees the result.

Use to normalise heterogeneous MCP payloads so Claude always sees one shape:

- Unix timestamps → ISO 8601
- Numeric status codes → human-readable strings
- Strip verbose fields the model does not need (also a Domain 5 context win)

The model then reasons over clean data regardless of which server produced it.

PostToolUse can also inspect a result and trigger escalation (for example, a refund that already executed above policy — better to block **before** execution with PreToolUse).

## PreToolUse (tool-call interception)

Runs **before** the tool executes.

Use to:

- Block refunds above £500 / $500 and redirect to human escalation
- Enforce compliance checks on international transfers
- Deny tools until a session flag such as `identity_verified` is set

This is the SDK form of the 1.4 prerequisite gate.

## Decision framework

| Rule type | Mechanism |
|---|---|
| Must be followed 100% of the time | Hook |
| Preference, style, soft guideline | Prompt |

Do not use a hook to “be a bit friendlier”. Do not use a prompt to “never send an unscreened wire transfer”.

## Practice scenario

An agent occasionally processes international transfers without required compliance checks.

**Use a PreToolUse hook** that denies the transfer tool until compliance checks have succeeded (or that redirects to a compliance workflow). An enhanced prompt leaves a residual miss rate; one miss is a legal event.

## Check questions

1. Unix timestamps from one MCP server and ISO dates from another confuse the model. PreToolUse or PostToolUse? Why?
2. “Add the compliance checklist to the system prompt and add two few-shot examples.” Why is that the wrong exam answer for transfers?

## Connects to 1.6

Hooks constrain *how* a step runs. Decomposition decides *which* steps exist and in what shape — chain vs adapt.
